## Project Overview

This project focuses on **fine-tuning multimodal web agents** for efficient, grounded action selection. Conducted at **Carnegie Mellon University** (2025), the work targets step optimization and behavior fine-tuning for web interaction tasks.

## Key Achievements

### Behavior Fine-Tuning
- Fine-tuning a **candidate-ranking multimodal agent** on **Mind2Web** for grounded action selection
- Developing preference-based training methods to improve agent decision quality

### Step Optimization
- **Preference-training** in **VisualWebArena** to minimize steps and decision errors
- Exploring tradeoffs between agent efficiency and task completion accuracy

## Technical Stack

- **Datasets**: Mind2Web, VisualWebArena
- **Techniques**: Multimodal fine-tuning, preference learning, grounded action selection
- **Frameworks**: PyTorch, HuggingFace

## Research Impact

This work advances efficient web agents that can perform complex tasks with fewer steps, reducing latency and improving user experience in human-AI collaboration settings.
