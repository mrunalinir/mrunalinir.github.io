## Project Overview

Personal project (July 2025 - August 2025) building a **multimodal financial market movement prediction** model that combines multiple data sources for more accurate and interpretable forecasts.

## Key Achievements

### Multimodal Forecasting
- Combined **stock prices**, **financial news**, **tweets**, and **firm metadata** in a unified model
- Achieved **14% accuracy gain** over unimodal baselines

### Time-Safe RAG Layer
- Added a RAG layer that pulls latest news and converts it into JSON event tags
- Provided short, **cited explanations** next to predictions for enhanced interpretability

### Analyst UI
- Deployed an analyst interface that ranks tickers (top-10 gainers/losers)
- Flagged high-confidence signals and linked to the exact retrieved news powering each forecast

## Technical Stack

- **Data**: Stock prices, financial news, social media, firm metadata
- **Techniques**: Multimodal fusion, temporal modeling, RAG for interpretability
- **Tools**: Python, PyTorch
